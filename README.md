# gritech-rakazo-plugin

Plugin pour Rakazo : skills seulement pour l'instant (pas de serveur MCP).

- `gritech-trading-guardrails` : contrôles avant tout ordre de trading.
- `gritech-team-lead` : méthode de chef pour un groupe de bots.

Installation : Rakazo → Intégrations → + → From GitHub → coller l'URL du dépôt → Preview → Add skills.

Aucun secret dans ce dépôt. Les accès (n8n, Capital.com) se configurent dans Rakazo.
